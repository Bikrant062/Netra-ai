# Netra AI 👁️

**An AI-powered bilingual visual assistant for visually impaired people.**

Netra AI is a web-based application that helps visually impaired individuals understand their surroundings through a camera and voice interaction.

### Planned Features
- Real-time camera access
- Object detection and identification
- Left, center, and right spatial awareness
- Voice-based questions and responses
- English and Nepali language support
- Text-to-speech responses

### Technology Stack
- HTML, CSS, JavaScript
- Python and FastAPI
- OpenCV
- Lightweight computer vision models

### Project Status
🚧 Under Development

### Goal
To develop an affordable AI-based accessibility tool that provides useful visual information without requiring additional hardware or paid AI services.
